# Runtime dependencies. Deliberately small: this is what a first-time user
# waits for, and every extra package is download time before they can ask a
# question.
#
# The openai package also drives Groq, which uses an OpenAI-compatible
# endpoint, so these four cover the recommended setup.
fastapi
uvicorn
python-dotenv
openai

# Windows has no system timezone database, and zoneinfo reads the OS copy.
# Without this the app cannot start on Windows at all.
tzdata; sys_platform == "win32"
